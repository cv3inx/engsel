# How to Run in TERMUX / LINUX

1. **Update & Upgrade Termux**

```bash
apt update && apt upgrade -y
````

2. **Install Git**

```bash
apt install git -y
```

3. **Clone this repository**

```bash
git clone https://github.com/cv3inx/engsel
```

4. **Open the folder**

```bash
cd reedem
```

5. **Setup**

```bash
bash setup.sh
```

6. **Run the script**

```bash
python main.py
```
